# @walter-sql/client

[Walter](https://walter.ax) keeps SQL query results up to date as data changes in Postgres.

Use this package in your application server to subscribe to live queries and pass updates to your app. Requires Node.js 22 or later.

```sh
npm install @walter-sql/client
```

All exports from `@walter-sql/view` are included; no separate install is needed.

**[Documentation: add live data to your app](https://walter.ax/docs/your-app/)**
