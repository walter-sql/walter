# @walter-sql/tanstack-query

[Walter](https://walter.ax) keeps SQL query results up to date as data changes in Postgres.

Use this package to keep TanStack Query's cached rows up to date from Walter subscriptions, or fetch a single result.

```sh
npm install @walter-sql/tanstack-query
```

Requires `@tanstack/query-core` >=5, provided by your TanStack Query adapter. All exports from `@walter-sql/view` are included; no separate install is needed.

**[Documentation: oRPC and TanStack Query](https://walter.ax/docs/orpc-tanstack/)**
