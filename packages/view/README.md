# @walter-sql/view

[Walter](https://walter.ax) keeps SQL query results up to date as data changes in Postgres.

Use this package directly in apps that manage their own UI state to turn incoming Walter messages into rows. Runs anywhere JavaScript runs.

```sh
npm install @walter-sql/view
```

All exports are also available from `@walter-sql/client` and `@walter-sql/tanstack-query`; no separate view package install is needed when using either.

**[Documentation: view and stream helpers](https://walter.ax/docs/javascript-client/#view-and-viewmessage)**
